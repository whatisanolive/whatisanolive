There is exactly one idea you need for this one:

> **_Probably our first sorting algorithm, definitely the most boring, so boring in fact that it puts the CPU to sleep when applied on a larger dataset._**

_The algorithm basically "bubbles" up the largest element to the last, and this continues till the list is sorted. It does so by constantly comparing the adjacent elements and swapping them if they are out of order._

## The problem

_Rearrange the list in ascending order so your OCD can finally rest:_

```plaintext
Input:  [3, 1, 6, 7, 2, -7, 8]
Output: [-7, 1, 2, 3, 6, 7, 8]
```

## Brute force first

_The naive approach is to blindly run nested loops n times, doing unnecessary comparisons even if the array sorted itself out on the very first pass. It’s the algorithmic equivalent of checking your fridge every 5 minutes hoping new groceries magically appeared (never does btw)._

```python
def bubble_sort_slow(nums):
    n = len(nums)
    for i in range(n):
        for j in range(1, n - i):
            if nums[j-1] > nums[j]:
                nums[j-1], nums[j] = nums[j], nums[j-1]
    return nums
```

| Time       | Space     |
| ---------- | --------- |
| O(n²)      | O(1)      |
## The better approach

_We introduce a boolean Flag and if we ever go a full sweep without any swaps, which means the list is already sorted and we bail out early. Saves us from the redundant iterations._

```python
def bubble_sort(nums):
    if not nums:
        return "Empty list"
  
    n = len(nums)
    flag = True
    while flag:
        flag = False
        for i in range(1,n):
            if nums[i-1] > nums[i]:
                nums[i-1] , nums[i] = nums[i] , nums[i-1]
                flag = True

    return nums
```

| Time       | Space     |
| ---------- | --------- |
| O(n²)/O(n) | O(1)      |

If the list is already sorted (best case), then the iteration stops immediately, therefore best case O(n) time complexity. On average it's time complexity is still O(n²)

The space complexity stays at O(1) because we're sorting entirely in-place.
